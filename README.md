this project is friend chat bot which as it's obvious, it connects two people
And they can start chatting and see eachother's profile 
Bot features:
  1. Set profile
  2. It recovers stranded users who are stranded when server crashes
  3. REDIS is used in this project so data will be loaded faster
  4. Every user has coins that is payed for chatting with other users
  5. Chat-request has expiration which is handled by REDIS and sorted list
